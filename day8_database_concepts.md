# Day 8 — Database & SQLAlchemy Concepts

## 1. Fake Database vs Real Database

A fake database is usually an in-memory Python list/dictionary that loses data when the program stops, while a real database permanently stores structured data.

## 2. What is SQL?

SQL (Structured Query Language) is the language used to create, read, update, and delete data in relational databases.

## 3. What does SQLAlchemy do?

SQLAlchemy is a Python library that lets Python applications communicate with relational databases and work with their data.

## 4. What is ORM?

ORM stands for Object-Relational Mapping; it maps Python objects/classes to database tables/rows so you can work with databases using Python.

## 5. Pydantic Model vs SQLAlchemy Model

Pydantic models validate/structure API request and response data, while SQLAlchemy models represent database tables and their records.
